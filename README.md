# DexLang & DexIDE  
A lightweight programming language and custom IDE built from scratch.

DexLang is a simple interpreted language written in Java.  
DexIDE is a custom-built GUI editor that lets you write, run, and build DexLang programs with ease.

---

## 🚀 Features

### ✅ DexLang (The Language)
- Integer variables  
- Arithmetic operations  
- While loops  
- If/else  
- Print statements  
- Blocks `{ ... }`  
- Simple interpreter written in Java  
- Easy to extend with new features  

### ✅ DexIDE (The Beast IDE)
- Open / Save `.dex` files  
- Run DexLang code directly  
- Choose a project root folder  
- Build system that generates:
  - `.dex-output/` folder  
  - `.dex-output/program.dex`  
  - `.dex-output/lastBuild.log`  
  - `.dex-output/lastRun.txt`  
  - `.dex-output/.dexDump/` (history of all builds)  
- Console output panel  
- Clean Swing UI
